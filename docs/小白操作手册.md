# 小白操作手册（照着做就行）

这份文档是给完全不熟悉 Linux 的人看的。每一步都写清楚「点哪里、复制什么、粘贴到哪」。

---

## 一、先搞清楚这套东西在干什么

你的阿里云服务器每个月有一定的**免费流量额度**（叫 CDT，云数据传输）。
超过额度就开始扣钱，扣起来很快。

这套脚本帮你做三件事：

1. **盯着流量**：每 5 分钟查一次，用了多少。
2. **快超标就关机**：到阈值自动关机，不让它继续跑流量。
3. **下月自动开回来**：流量额度重置后自动开机，并每天给你发一份报表。

## 二、准备工作（只需做一次）

### 2.1 拿到 AccessKey（相当于给脚本一把钥匙）

1. 浏览器打开 `https://ram.console.aliyun.com/users`
2. 点 **创建用户**
3. 登录名称随便填，例如 `cdt-guard`
4. 勾选 **使用永久 AccessKey 访问**
5. 点确定，弹出窗口里有两串字符：
   - **AccessKey ID**（较短的）
   - **AccessKey Secret**（较长的）
6. **立刻复制到记事本保存**，关掉窗口后就再也看不到了

> 安全提醒：千万不要用主账号的 AccessKey。万一泄露，整个账号的钱都不安全。

### 2.2 给这个用户授权

在用户列表里点刚创建的用户 → 权限管理 → 新增授权 → 搜索并添加这三个：

- `AliyunECSFullAccess`
- `AliyunCDTReadOnlyAccess`
- `AliyunBSSReadOnlyAccess`

### 2.3 拿到你的实例 ID

1. 打开 `https://ecs.console.aliyun.com`
2. 找到你的服务器，复制**实例 ID**（形如 `i-bp1xxxxxxxx`）
3. 同时记住它所在的**地域**（例如「中国香港」对应 `cn-hongkong`）

### 2.4 配置 Telegram 通知（必须）

1. App 里搜索 `@BotFather`，发送 `/newbot`
2. 按提示给机器人起名，它会回复一串 Token，复制保存
3. App 里搜索 `@userinfobot`，发送任意消息
4. 它会回复你的数字 ID，复制保存

> 为什么必须配 Telegram？因为**所有告警都只走 Telegram**。
> 不配的话，机器被止损关机了你完全不知道。

### 2.5 配置 QQ 推送（可选，两个方案二选一）

**方案 A：NapCat / OneBot（推荐，能收告警）**

自己搭的 QQ 机器人，没有配额限制，可以正常收告警。

1. 找一台常开的机器（可以就是本机），按 NapCat 官方文档部署
2. 在 NapCat 配置里开启 **HTTP 服务**（默认端口通常 3000）
3. 记下 HTTP 地址（如 `http://127.0.0.1:3000`）和它设置的 Token
4. 安装脚本里填这些信息，再填一个群号就行

**方案 B：QQ 官方机器人（备选，只能收日报）**

**先说清楚限制**：腾讯规定 QQ 机器人群聊主动消息**每月只有 4 条**。
所以这条路只用来发日报摘要，**收不到告警**。

1. 浏览器打开 `https://q.qq.com`，注册并创建机器人
2. 在管理端拿到 **AppID** 和 **AppSecret**
3. 把机器人拉进你的 QQ 群
4. 在群里 @ 一下机器人，然后执行
   `tail -n 50 /opt/cdt-guard/report.log` 从日志里找到群的 OpenID

## 三、开始安装

### 3.1 登录你的服务器

Windows 用户打开 PowerShell，输入：

```bash
ssh root@你的服务器公网IP
```

回车后输入密码（输入时屏幕不显示，输完直接回车）。

### 3.2 执行安装命令

复制下面这一整行，粘贴进 PowerShell，回车：

```bash
bash <(curl -sL https://raw.githubusercontent.com/yys9253462-gif/aliyun-cdt-guard/main/install.sh)
```

### 3.3 跟着提示填写

脚本会一步步问你，照下面的对照表填：

| 提示 | 你该填什么 |
| --- | --- |
| 粘贴 Bot Token | 2.4 步拿到的 Token |
| 粘贴你的数字 ID | 2.4 步拿到的数字 ID |
| 【方案A】OneBot HTTP 地址 | 2.5 步方案 A 的地址，不用就回车跳过 |
| OneBot 访问 Token | 2.5 步方案 A 的 Token，没设置就回车 |
| 推送目标类型（方案A） | 填 `1` 发到群，填 `2` 发给人 |
| 群号 / QQ 号 | 2.5 步方案 A 的目标 |
| 【方案B】QQ 官方 AppID | 2.5 步方案 B 的 AppID，不用就回车跳过 |
| AppSecret | 2.5 步方案 B 的 AppSecret |
| 群 OpenID / 对方 OpenID | 2.5 步方案 B 从日志里拿到的 OpenID |
| 起个备注名 | 例如 `香港节点` |
| AccessKey ID | 2.1 步保存的 ID |
| AccessKey Secret | 2.1 步保存的 Secret |
| 账号类型 | 国内账号填 `1`，国际账号填 `2` |
| 选择要监控的机器 | **脚本会自动列出你账号下所有实例，填编号即可**，不用自己找地域和实例 ID |
| （若自动查询失败）实例所在地域 | 退回手动时才会问。按菜单数字选，菲律宾填 `3`（`ap-southeast-6`） |
| （若自动查询失败）ECS 实例 ID | 2.3 步复制的 ID |
| 关机阈值 | 直接回车用默认 180，或按你的额度改 |
| 资源组 ID | 不懂就直接回车 |
| 最低余额警戒线 | 直接回车用默认 10，填 `0` 表示不要这项提醒 |
| 账单警戒线 | 直接回车表示关闭。等你摸清每月正常花多少再打开 |

> **关于「选择要监控的机器」**：填完 AccessKey 后，脚本会自动查询你账号下
> **所有地域**的实例（约 10 秒），然后列出像这样的一张清单让你挑：
>
> ```
>    1) 菲律宾(马尼拉) ap-southeast-6  i-abc123  [Running]  我的站
>    2) 中国香港 cn-hongkong           i-def456  [Stopped]
>
> 共找到 2 台实例，请选择要监控的那一台：
> （输入 0 可改为手动填写）
> 输入编号 [默认: 1]:
> ```
>
> 直接填编号就行，地域和实例 ID 会自动填好。
> 如果查不到（网络问题或权限不足），会让你手动填，也不影响使用。

填完后等 3-5 分钟，最后会显示「安装全部完成」。

装完还会自动给你装一个 **Telegram 机器人**。看到这句就说明好了：

```
[完成] 机器人已启动。打开 Telegram 给机器人发 /menu 试试。
```

## 四、验证是否装好

安装结束后脚本会自动做一次自检，你会看到类似：

```
[正常] 香港节点 流量查询成功：12.34 GB
[正常] Telegram
[正常] Telegram 通道测试成功
自检完成：至少一个通知渠道可用，测试消息已发出。
```

**收到测试通知 = 安装成功。**

装完后打开 Telegram，给你的机器人发一句 `/menu`，
如果底部弹出一排按钮（输入框下面那一片），说明**机器人也装好了**。

如果显示「流量查询失败」，按提示排查：

| 报错关键字 | 原因 | 怎么办 |
| --- | --- | --- |
| `InvalidAccessKeyId` | AK 填错了 | 重新运行安装脚本进菜单改配置 |
| `Forbidden` | 没授权 | 回到 2.2 步补权限 |
| `InvalidInstanceId` | 实例 ID 或地域填错 | 重新进菜单改 |

如果 Telegram 显示「失败」，但自检说「网络可达」：

| 报错关键字 | 原因 | 怎么办 |
| --- | --- | --- |
| `403 Forbidden` + `can't send messages to the bot` | **Chat ID 填成了机器人自己的 ID** | Chat ID 是**你个人**的数字 ID（从 `@userinfobot` 拿），不是机器人 ID。机器人 ID 是 Token 冒号前面那串数字。重新进菜单第 5 项改 |
| `404 Not Found` | Token 填错，或机器人已被删除 | 回 `@BotFather` 重新拿 Token |
| 提示「需要配置代理」 | 本机连不上 Telegram | 阿里云海外节点一般可直连；国内节点需要给脚本配代理 |

#### 🏦 账号汇总是什么？什么时候用？

先说清楚一件容易搞错的事：**阿里云的免费流量额度是按「账号」算的，不是按机器算的。**

也就是说，如果你在同一个阿里云账号下有 3 台机器，
它们**共享**那 200GB（非中国内地）额度，不是每台各 200GB。

所以「逐台看流量」在某些时候会误判：
每台看起来都才用了 60GB，好像都很安全，加起来其实已经 180GB 了。

点「🏦 账号汇总」，机器人会按 AccessKey 把机器分组，告诉你：

```
🏦 按账号汇总
（免费额度按账号计算，同一账号下所有机器共享）

* 账号 LTAI5t****（2 台机器）
  · 菲律宾节点
  · 新加坡节点
  账号本月总用量: 12.40 GB
  非中国内地额度: 200 GB，已用 6.2%，剩 187.60 GB
```

两个细节：

- **每个账号只查一次接口。** 因为接口返回的本来就是整个账号的用量，
  把每台机器的查询结果相加会重复算，数字直接翻倍。
- **AccessKey 会打码**（只留前 6 位），因为报表可能被你转发给别人。

> 配了 **2 个以上**账号时，每天早上那份完整报表的末尾也会自动附上这一段；
> 只有 1 个账号时不显示 —— 单个账号的汇总和明细完全重复，没必要占篇幅。

| 按钮 | 作用 |
| --- | --- |
| 📊 状态 | 看这台机器在跑还是停了 |
| 🚀 开机 | 手动把它开起来 |
| 🛑 关机 | 手动把它关掉（不影响自动止损） |
| ⏸️ 暂停监控 | 不再自动管这台机器（按钮会变成「▶️ 恢复监控」） |

| 🏠 返回主菜单 | 回第一层 |

> **按钮就是快捷输入。** 点按钮等于替你打了一句话发出去。
> 所以你既可以直接点按钮，也可以手打「总览」两个字，效果完全一样。

也可以直接发命令，不用点按钮：

| 命令 | 作用 |
| --- | --- |
| `/menu` | 打开菜单 |
| `/status` | 查看所有机器状态 |
| `/traffic` | 查看流量与免费额度 |
| `/balance` | 查看账户余额与本月账单 |
| `/accounts` | 按账号汇总额度占用 |

| `/report` | 立即发一份完整报表 |
| `/run` | 立刻跑一次巡检 |
| `/help` | 使用说明 |

> **只有你能操作。** 机器人只认你配置里那个 Chat ID。
> 别人就算找到你的机器人、发消息、点按钮，都不会有任何反应，
> 更不可能关掉你的机器。这是安全设计，不用改。

> **机器人挂了不影响止损。** 机器人和定时巡检是两个独立进程。
> 就算机器人进程出问题，流量监控和自动关机照样正常工作。

### 5.2 收到告警怎么办

| 你收到的消息 | 意思 | 要做什么 |
| --- | --- | --- |
| 「已恢复运行」 | 流量安全，机器自动开机了 | 不用管 |
| 「流量超标已止损」 | 到阈值了，机器已关机 | 不用管，等下月自动恢复；急用可手动开机 |
| 「开机失败」/「开机未成功」 | 库存不足开不起来 | 不用管，脚本每 30 分钟自动重试 |
| 「止损关机失败」 | 关机指令没下发成功 | **立刻登录阿里云控制台手动关机！** |
| 「监控异常」 | 连续 3 次查不到数据 | 检查服务器网络是否正常 |
| 「实例已停止」 | 机器从运行中掉线了 | 不是你主动关的就留意一下；脚本会按规则自动开机 |
| 「免费额度即将用尽」 | 用到额度的 80% 或 95% 了 | 心里有数，接近开始花钱了 |
| 「账户余额过低」 | 余额低于你设的警戒线 | 尽快充值，欠费会被停机 |
| 「账户已欠费」 | 余额已经是负的 | **马上充值**，实例随时可能被停 |
| 「本月账单超支」 | 账单超过你设的线 | 去阿里云「费用中心」核对明细 |

### 5.5 机器人不理我了怎么办

按顺序检查：

1. 菜单选 `11`，看机器人是不是在运行。不在就选 `10` 重装一次。
2. 看 `bot.log` 最后几行有没有报错。
3. 如果日志里出现 `Conflict` 或 `terminated by other getUpdates request`：
   说明有另一个机器人在同时轮询同一个 Bot（比如你在两台机器上装了同一套）。
   把多余的那个停掉。
4. 如果日志里说连不上 `api.telegram.org`：本机网络受限，需要配代理。

**如果只是「底部按钮不见了」：**

- 底部菜单是 Telegram 客户端自己的功能。如果你不小心点了「❌ 收起菜单」，
  或者点了输入框旁边那个小图标，按钮就会收起来。
  **发一句 `/menu` 就能重新打开**，不用重装。

**如果「点按钮没反应」：**

- 先确认你是不是**在私聊里**点的。回复键盘只在私聊和群聊的正常输入框里显示。
- 如果点了按钮弹出「没听懂」的提示：说明菜单文字和机器人认的文字对不上。
  这种情况请把 `bot.log` 发给开发者，同时附上你点的是哪个按钮。
- 如果点了完全没反应、连提示都没有：大概率是机器人进程挂了，选 `11` 查一下。

**如果「点某台机器的按钮，进不去第二层」：**

- 确认这台机器还在监控列表里（菜单选 `1` 可以看）。
  如果机器被删掉了，点它的按钮会提示「没找到这台机器」。

**如果「我想再加一个阿里云账号的机器，怎么办」：**

- 直接**重新运行一次安装脚本**，进入管理菜单，选增加机器的选项，
  填新账号的 AccessKey / AccessKeySecret 和地域即可。旧配置不会被覆盖。
- 加完之后点「🏦 账号汇总」，就能看到两个账号各自的额度占用情况。
  机器人**不需要重新绑定** —— 它认的是你的 Telegram Chat ID，与阿里云账号无关，
  加多少个阿里云账号都还是同一个机器人。
- ⚠️ 注意：如果新加的是**同一个主账号下的子账号**，那它们的额度实际上是**共享的**，
  汇总里会给出提醒。真正独立算额度的是**完全独立的主账号**。

## 六、常见问题

**问：关机后我的服务不就断了？**
答：是的。这正是这套脚本的目的——宁可断服务，也不要被扣钱。
如果你希望「宁可扣钱也不能断」，把阈值调高（比如 500）即可。

**问：自检报 `Forbidden: the bot can't send messages to the bot` 是什么意思？**
答：**你把 Chat ID 填成机器人自己的 ID 了。**
Bot Token 的格式是 `<机器人ID>:<密钥>`，冒号前面那串是机器人自己的编号，
**不是你的 Chat ID**。Chat ID 是你的个人账号编号，取法见 2.4 步：
先给机器人发一条消息，再访问 `https://api.telegram.org/bot<你的Token>/getUpdates`，
从返回里找 `"chat":{"id": 数字}`，那个数字才是。
（典型特征：Chat ID 通常 9-10 位，且**和 Token 冒号前的数字不一样**。）

**问：安装最后报了一大串 `AttributeError: 'NoneType' object has no attribute 'error'` 怎么办？**
答：这是旧版本的缺陷，**已在最新版修掉**。重新运行一次安装脚本即可。
（该报错本身不影响巡检和止损功能，只是自检发送测试通知时崩了。）
如果 Telegram 收不到消息，看自检输出里那一行 `[失败] Telegram 网络不通` 或
`[失败] Telegram`，后面会直接告诉你原因（网络受限 / Token 错 / Chat ID 错）。

**问：自检显示「流量查询成功：0.00 GB」，正常吗？**
答：可能是本计费周期确实还没跑流量，也可能是 CDT 数据有延迟。
判断办法：去阿里云控制台「云数据传输 CDT」页面看用量，两边对得上就没问题。
若控制台有流量而这里恒为 0，请检查该 RAM 用户是否授予了 `AliyunCDTReadOnlyAccess`。

**问：我的机器在菲律宾，选择列表里怎么没有？**
答：现在已经**不用你自己选了**。填完 AccessKey 后脚本会自动扫描账号下**所有地域**
的实例，菲律宾（马尼拉）会自动出现在列表里。万一自动查询失败退回手动填写，
菲律宾是 `ap-southeast-6`，选编号 `3` 即可。

**问：阈值设多少合适？**
答：看你的免费额度。比如额度 200GB，设 180 留一点缓冲最稳妥。

**问：抢占式实例被回收了，这套脚本能救吗？**
答：不能。抢占式实例被**彻底回收**（不是简单关机）后机器都没了，脚本救不了。
这种情况请用阿里云官方的**弹性伸缩**服务自动新建实例。

**问：脚本会不会把我的密钥泄露？**
答：配置文件锁在 `/opt/cdt-guard/config.json`，权限是 600（只有 root 能读）。
日志里所有密钥类字段都做了遮蔽处理。但仍然建议用 RAM 子账号，且只授予必要权限。

**问：为什么 QQ 官方机器人收不到告警，只有日报？**
答：这是腾讯的限制，不是脚本的问题。QQ 官方机器人**群聊主动消息每月只有 4 条**，
配额一用完就发不出去。**想用 QQ 收告警，请改用 NapCat / OneBot 方案**，
它没有配额限制。

**问：NapCat 是什么，一定要装吗？**
答：NapCat 是一个开源的 QQ 机器人框架，装好之后你的脚本就能通过本地 HTTP 接口
给 QQ 发消息，不受腾讯官方配额限制。不想折腾的话，只用 Telegram 也完全够用。

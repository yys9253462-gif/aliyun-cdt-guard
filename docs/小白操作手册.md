# 小白操作手册（照着做就行）

这份文档是给完全不熟悉 Linux 的人看的。每一步都写清楚「点哪里、复制什么、粘贴到哪」。

---

## 一、先搞清楚这套东西在干什么

你的阿里云服务器每个月有一定的**免费流量额度**（叫 CDT，云数据传输）。
超过额度就开始扣钱，扣起来很快。

这套脚本帮你做三件事：

1. **盯着流量**：每 5 分钟查一次，用了多少。
2. **快超标就关机**：到阈值自动关机，不让它继续跑流量。
3. **下月自动开回来**：流量额度重置后自动开机，并每天给你发一份报表。

## 二、准备工作（只需做一次）

### 2.1 拿到 AccessKey（相当于给脚本一把钥匙）

1. 浏览器打开 `https://ram.console.aliyun.com/users`
2. 点 **创建用户**
3. 登录名称随便填，例如 `cdt-guard`
4. 勾选 **使用永久 AccessKey 访问**
5. 点确定，弹出窗口里有两串字符：
   - **AccessKey ID**（较短的）
   - **AccessKey Secret**（较长的）
6. **立刻复制到记事本保存**，关掉窗口后就再也看不到了

> 安全提醒：千万不要用主账号的 AccessKey。万一泄露，整个账号的钱都不安全。

### 2.2 给这个用户授权

在用户列表里点刚创建的用户 → 权限管理 → 新增授权 → 搜索并添加这三个：

- `AliyunECSFullAccess`
- `AliyunCDTReadOnlyAccess`
- `AliyunBSSReadOnlyAccess`

### 2.3 拿到你的实例 ID

1. 打开 `https://ecs.console.aliyun.com`
2. 找到你的服务器，复制**实例 ID**（形如 `i-bp1xxxxxxxx`）
3. 同时记住它所在的**地域**（例如「中国香港」对应 `cn-hongkong`）

### 2.4 配置 Telegram 通知（必须）

1. App 里搜索 `@BotFather`，发送 `/newbot`
2. 按提示给机器人起名，它会回复一串 Token，复制保存
3. App 里搜索 `@userinfobot`，发送任意消息
4. 它会回复你的数字 ID，复制保存

> 为什么必须配 Telegram？因为**所有告警都只走 Telegram**。
> 不配的话，机器被止损关机了你完全不知道。

### 2.5 配置 QQ 推送（可选，两个方案二选一）

**方案 A：NapCat / OneBot（推荐，能收告警）**

自己搭的 QQ 机器人，没有配额限制，可以正常收告警。

1. 找一台常开的机器（可以就是本机），按 NapCat 官方文档部署
2. 在 NapCat 配置里开启 **HTTP 服务**（默认端口通常 3000）
3. 记下 HTTP 地址（如 `http://127.0.0.1:3000`）和它设置的 Token
4. 安装脚本里填这些信息，再填一个群号就行

**方案 B：QQ 官方机器人（备选，只能收日报）**

**先说清楚限制**：腾讯规定 QQ 机器人群聊主动消息**每月只有 4 条**。
所以这条路只用来发日报摘要，**收不到告警**。

1. 浏览器打开 `https://q.qq.com`，注册并创建机器人
2. 在管理端拿到 **AppID** 和 **AppSecret**
3. 把机器人拉进你的 QQ 群
4. 在群里 @ 一下机器人，然后执行
   `tail -n 50 /opt/cdt-guard/report.log` 从日志里找到群的 OpenID

## 三、开始安装

### 3.1 登录你的服务器

Windows 用户打开 PowerShell，输入：

```bash
ssh root@你的服务器公网IP
```

回车后输入密码（输入时屏幕不显示，输完直接回车）。

### 3.2 执行安装命令

复制下面这一整行，粘贴进 PowerShell，回车：

```bash
bash <(curl -sL https://raw.githubusercontent.com/yys9253462-gif/aliyun-cdt-guard/main/install.sh)
```

### 3.3 跟着提示填写

脚本会一步步问你，照下面的对照表填：

| 提示 | 你该填什么 |
| --- | --- |
| 粘贴 Bot Token | 2.4 步拿到的 Token |
| 粘贴你的数字 ID | 2.4 步拿到的数字 ID |
| 【方案A】OneBot HTTP 地址 | 2.5 步方案 A 的地址，不用就回车跳过 |
| OneBot 访问 Token | 2.5 步方案 A 的 Token，没设置就回车 |
| 推送目标类型（方案A） | 填 `1` 发到群，填 `2` 发给人 |
| 群号 / QQ 号 | 2.5 步方案 A 的目标 |
| 【方案B】QQ 官方 AppID | 2.5 步方案 B 的 AppID，不用就回车跳过 |
| AppSecret | 2.5 步方案 B 的 AppSecret |
| 群 OpenID / 对方 OpenID | 2.5 步方案 B 从日志里拿到的 OpenID |
| 起个备注名 | 例如 `香港节点` |
| AccessKey ID | 2.1 步保存的 ID |
| AccessKey Secret | 2.1 步保存的 Secret |
| 账号类型 | 国内账号填 `1`，国际账号填 `2` |
| 选择要监控的机器 | **脚本会自动列出你账号下所有实例，填编号即可**，不用自己找地域和实例 ID |
| （若自动查询失败）实例所在地域 | 退回手动时才会问。按菜单数字选，菲律宾填 `3`（`ap-southeast-6`） |
| （若自动查询失败）ECS 实例 ID | 2.3 步复制的 ID |
| 关机阈值 | 直接回车用默认 180，或按你的额度改 |
| 资源组 ID | 不懂就直接回车 |

> **关于「选择要监控的机器」**：填完 AccessKey 后，脚本会自动查询你账号下
> **所有地域**的实例（约 10 秒），然后列出像这样的一张清单让你挑：
>
> ```
>    1) 菲律宾(马尼拉) ap-southeast-6  i-abc123  [Running]  我的站
>    2) 中国香港 cn-hongkong           i-def456  [Stopped]
>
> 共找到 2 台实例，请选择要监控的那一台：
> （输入 0 可改为手动填写）
> 输入编号 [默认: 1]:
> ```
>
> 直接填编号就行，地域和实例 ID 会自动填好。
> 如果查不到（网络问题或权限不足），会让你手动填，也不影响使用。

填完后等 3-5 分钟，最后会显示「安装全部完成」。

## 四、验证是否装好

安装结束后脚本会自动做一次自检，你会看到类似：

```
[正常] 香港节点 流量查询成功：12.34 GB
已尝试发送一条测试通知，请查看你的手机是否收到。
```

**收到测试通知 = 安装成功。**

如果显示「流量查询失败」，按提示排查：

| 报错关键字 | 原因 | 怎么办 |
| --- | --- | --- |
| `InvalidAccessKeyId` | AK 填错了 | 重新运行安装脚本进菜单改配置 |
| `Forbidden` | 没授权 | 回到 2.2 步补权限 |
| `InvalidInstanceId` | 实例 ID 或地域填错 | 重新进菜单改 |

## 五、日常怎么用

### 5.1 收到告警怎么办

| 你收到的消息 | 意思 | 要做什么 |
| --- | --- | --- |
| 「已恢复运行」 | 流量安全，机器自动开机了 | 不用管 |
| 「流量超标已止损」 | 到阈值了，机器已关机 | 不用管，等下月自动恢复；急用可手动开机 |
| 「开机失败」/「开机未成功」 | 库存不足开不起来 | 不用管，脚本每 30 分钟自动重试 |
| 「止损关机失败」 | 关机指令没下发成功 | **立刻登录阿里云控制台手动关机！** |
| 「监控异常」 | 连续 3 次查不到数据 | 检查服务器网络是否正常 |

### 5.2 想改配置

重新运行安装命令就行：

```bash
bash <(curl -sL https://raw.githubusercontent.com/yys9253462-gif/aliyun-cdt-guard/main/install.sh)
```

会看到中文菜单，输入数字选择要做的操作。

### 5.3 想看日志

菜单里选 `8`，或者直接：

```bash
tail -f /opt/cdt-guard/guard.log
```

按 `Ctrl + C` 退出查看。

## 六、常见问题

**问：关机后我的服务不就断了？**
答：是的。这正是这套脚本的目的——宁可断服务，也不要被扣钱。
如果你希望「宁可扣钱也不能断」，把阈值调高（比如 500）即可。

**问：我的机器在菲律宾，选择列表里怎么没有？**
答：现在已经**不用你自己选了**。填完 AccessKey 后脚本会自动扫描账号下**所有地域**
的实例，菲律宾（马尼拉）会自动出现在列表里。万一自动查询失败退回手动填写，
菲律宾是 `ap-southeast-6`，选编号 `3` 即可。

**问：阈值设多少合适？**
答：看你的免费额度。比如额度 200GB，设 180 留一点缓冲最稳妥。

**问：抢占式实例被回收了，这套脚本能救吗？**
答：不能。抢占式实例被**彻底回收**（不是简单关机）后机器都没了，脚本救不了。
这种情况请用阿里云官方的**弹性伸缩**服务自动新建实例。

**问：脚本会不会把我的密钥泄露？**
答：配置文件锁在 `/opt/cdt-guard/config.json`，权限是 600（只有 root 能读）。
日志里所有密钥类字段都做了遮蔽处理。但仍然建议用 RAM 子账号，且只授予必要权限。

**问：为什么 QQ 官方机器人收不到告警，只有日报？**
答：这是腾讯的限制，不是脚本的问题。QQ 官方机器人**群聊主动消息每月只有 4 条**，
配额一用完就发不出去。**想用 QQ 收告警，请改用 NapCat / OneBot 方案**，
它没有配额限制。

**问：NapCat 是什么，一定要装吗？**
答：NapCat 是一个开源的 QQ 机器人框架，装好之后你的脚本就能通过本地 HTTP 接口
给 QQ 发消息，不受腾讯官方配额限制。不想折腾的话，只用 Telegram 也完全够用。

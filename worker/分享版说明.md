## 开始使用
1. 解压整个 ZIP，不要只取启动文件。
2. Windows 双击「启动.bat」，按环境体检提示准备 Git for Windows、Node.js 22 或更高版本（推荐当前 LTS）。
3. 选「2 一站式安装」，完成你自己的 Cloudflare 授权。
4. 输入你自己的机器人 Token（输入隐藏），随后填写你自己的 Telegram 数字 ID。
5. 完成机器配置和自检。只有 Webhook 自检通过，才算安装完成。
6. 在 Telegram 私聊你的机器人发送 /menu 验证回复。

包内没有作者的登录态、密钥、KV 编号、机器配置或部署网址。每个使用者都需要配置自己的账号。
需要联网访问 GitHub、npm、Cloudflare、Telegram。网络失败时不要把「状态无法确认」当成未部署。

## 已安装用户
- 仅绑定机器人 ID：Git Bash 执行 `bash deploy.sh bind-chat`，保留原机器清单。
- 注册/检查 Webhook：`bash deploy.sh selfcheck`。
- 退出脚本登录：`wrangler logout`，不会删除已部署的 Worker。

## 本次修复
- 登录与 KV 配置解耦，避免首次登录死循环和 whoami 退出码误判。
- Worker 状态核对当前认证账号，不读取旧账号网址缓存。
- 恢复中断后残留的临时注释配置，复用现有 KV，避免重复创建同名空间。
- Token 后立即绑定用户数字 ID，新 KV 缺配置时安全初始化；合并时保留原机器清单。
- 自检失败停止安装，不再显示「全部完成」；配置后再设置和回读 Webhook。
- Wrangler 固定到验证过的 4.130.0；依赖清单与锁文件同步。

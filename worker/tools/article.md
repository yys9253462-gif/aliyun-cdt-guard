# 阿里云流量超额，我是怎么让机器人替我关机的

我一直有个习惯：看到便宜的云服务器就想开一台。

菲律宾马尼拉的一台小机器，用来跑点定时任务，平时流量很低。但阿里云 CDT 有个坑 —— 公网出流量超出免费额度后，单价并不便宜。不是那种"多花几块钱"的量级。

更要命的是，我人不在电脑前。等发现的时候，账单已经出来了。

所以我做了个东西：一个跑在 Cloudflare 上的机器人，流量快超标时替我关机，下个月流量重置后替我开机。

## 先说结论：为什么不能装在被监控的机器上

我一开始就是这么干的 —— 把脚本装在那台机器自己身上。

然后发现一个死循环：

- 流量超标 → 脚本把机器关机了，省钱 ✅
- 但脚本**也在那台机器上**，跟着一起死了
- 下个月流量重置，没人去开机 ❌

要去叫醒一扇门里的人，你得站在门外。

这句话是这个项目所有设计的起点。

## 搬到 Cloudflare 之后

整套逻辑跑在 Cloudflare Workers 上，跟被监控的机器完全没关系。机器关机对它毫无影响 —— 它反而是唯一能把机器叫醒的东西。

免费额度是每天 10 万次请求，实际用量每天大概 300 次。**它不要钱。**

装好之后，你在 Telegram 上有个机器人，菜单是这样的：

- 📊 总览 / 📈 流量额度 / 📡 实例状态
- 💰 余额详情 / 🏦 账号汇总
- 🚀 全部开机 / 🛑 全部关机
- ➕ 添加账号

不用记命令，点就行。

## 它替我做三件事

### 一、提前止损

每 5 分钟查一次流量和状态。超过你设的阈值，立刻强制关机，同时发消息告诉你。

不等到出账单才后悔。

### 二、自动复活

这是我最在意的功能。

机器关掉之后，它还在盯着。下个月 1 号流量重置成 0，只要降到安全线以下，它会**自动把机器开回来**。

你什么都不用做。睡一觉起来，机器已经在跑了。

### 三、出事了能通知你

机器被意外停机、余额低于警戒线、流量用到 80% / 95%，都会推消息。不是静默失败。

## 手机上就能加账号

免费额度是按**账号**算的（内地 20 GB / 非内地 200 GB），不是按机器。所以多开几个账号分开跑，每个账号各算各的额度，挺划算。

加账号不用碰电脑，在机器人里点「➕ 添加账号」，然后：

1. 发 AccessKey ID
2. 发 AccessKey Secret（收到后机器人**立刻删掉这条消息**）
3. 它自动去这个账号里扫一遍，把所有机器列出来
4. 你点「✅ 全部加入监控」，完事

不用去控制台手抄实例 ID，不用填地域。扫到什么就给你配好什么。

## 两个我踩过的坑，顺便说一下

**第一个：别用主账号的 AccessKey。**

给它建个 RAM 子账号，只放开机 / 关机 / 查询这三类权限。万一泄露，损失可控。

**第二个：在聊天窗口发密钥本身不是最安全的做法。**

这个我不否认。为了"手机上就能加账号"的便利，我做了这些补偿：收到密钥的消息立刻删除、扫描期间只在临时会话里存 15 分钟、展示配置时永远打码（只露前 6 后 4）。

够用，但不能说万无一失。你自己权衡。

## 怎么装

一台能上网的电脑，装个 Node.js，然后跑：

```bash
bash menu.sh
```

打开是个中文菜单，当前状态一眼可见（Node 装没装、Cloudflare 登没登、配了几台机器）。第一次用选「1 环境体检」，它会告诉你缺什么、按你的系统给安装命令。

然后一路点下去就行。

# 阿里云流量守护机器人：安装步骤

## 一、作用

阿里云 CDT 公网出流量超出免费额度后会扣费。这套工具跑在 Cloudflare 上，流量快超标时替你关机，下个月流量重置后替你开机。

**不要装在被监控的机器上。** 机器一关机，脚本自己也死了，就没人去开机。必须装在机器外面。

## 二、准备

- 一台能上网的电脑
- Cloudflare 账号（免费注册）
- Telegram 账号
- 阿里云 AccessKey

建议给阿里云建一个 RAM 子账号，只给开机 / 关机 / 查询权限，不要用主账号。

## 三、安装步骤

### 1. 装 Node.js

去 https://nodejs.org 下载 LTS 版本，一路下一步装完。

验证：

```bash
node -v
```

能显示版本号就行。

### 2. 解压安装包

下载 `cdt-guard-worker-20261010.tar.gz`，解压并进入目录：

```bash
tar -xzf cdt-guard-worker-20261010.tar.gz
cd cdt-guard-worker
```

### 3. 打开菜单

```bash
bash menu.sh
```

会看到中文菜单，顶部显示当前状态（Node 装没装、Cloudflare 登没登、配了几台机器）。

### 4. 选「1 环境体检」

检查缺什么，并按你的系统给出安装命令。按提示装完。

### 5. 选「2 一站式安装」

按提示依次输入：

| 提示 | 填什么 |
|---|---|
| Telegram 机器人令牌 | 找 @BotFather 发 `/newbot`，拿到的令牌 |
| Telegram 数字 ID | 找 @userinfobot 发消息，拿到的数字 ID |
| 阿里云 AccessKey ID | 控制台创建的 AK |
| 阿里云 AccessKey Secret | 对应的 SK |
| 实例 ID | 要监控的机器，`i-` 开头 |
| 地域 | 机器所在地域，如 `ap-southeast-6` |
| 流量阈值 | 建议 180（GB） |

### 6. 等自检跑完

安装最后会自动测一遍，屏幕逐条显示结果。全部「成功」就装好了。

## 四、验证

在 Telegram 给机器人发：

```
/menu
```

底部跳出一排中文按钮。点「📊 总览」能看到机器状态和流量，说明通了。

## 五、常用操作

| 要做什么 | 怎么操作 |
|---|---|
| 看流量 | 点「📈 流量额度」 |
| 加阿里云账号 | 点「➕ 添加账号」，发 AK 和 Secret，自动扫出该账号所有机器，确认即可 |
| 手动开关机 | 点「🚀 全部开机」或「🛑 全部关机」 |
| 立即巡检 | 点「🔄 立即巡检」 |
